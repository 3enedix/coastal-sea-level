# Functions to process coastal geodetic and remote sensing data sets
This module contains functions that I'm writing while researching the impact of sea level rise on the position of a shoreline. Some of these functions are specific to the data sets I've been using and will only start to make sense once the repositories that use them are open (currently private because papers are under review). Others have more general use, e.g. the computation of a median shoreline from a set of satellite-derived shorelines. A more thorough [documentation](https://coastal-sea-level.readthedocs.io/en/latest/) of specific/generic funtions and their use cases will follow soon.

#### Installation
Clone the repository, then in the terminal navigate to `coastal_data`, create or choose an environment and install the module with `python3 -m pip install ./`
